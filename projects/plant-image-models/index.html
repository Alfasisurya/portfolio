Plant image models

  • Period2013–2021
  • StatusPublished

  • OrganizationMa Chung Research Center for Photosynthetic Pigments

This page groups published image methods from the Ma Chung years. It is not a company system.

Mata Daun, described in a 2013 conference paper, estimates soybean-leaf nitrogen from an RGB photograph by converting the image to an Enhanced Color Visibility index. A 2014 phone application uses fuzzy logic to turn soybean leaf color into a fertilizer-related color level. A 2019 paper uses a Hotelling T2 chart on citrus-leaf image features. Another 2019 paper uses transfer learning to separate three mangrove species from leaf shape. A 2018 conference paper compares convolutional networks for predicting chlorophyll, carotenoid, and anthocyanin from multispectral images. A 2019 journal paper compares ANFIS with ANN and Fuzzy-MLP for fine-flavor versus bulk cacao leaf color.

The numbers that the papers themselves print are kept on the publication pages. This project page does not add a new accuracy.
